Boat marker artwork is adapted from these open-source SVG icons and recolored
black for use on the map:

- `cruise-ship.png`: Normal boat silhouette supplied by the project user, cropped
  and recolored for use as a map marker.
- `slow-ship.png`: Freighter silhouette supplied by the project user, cropped
  and recolored for use as a map marker.
- `speedboat.svg`: Original project speedboat icon recolored black for use as a
  map marker, with the windshield retained as negative space.

Wildlife icons in `../wildlife/` (`manatee.png`, `alligator.png`) are made from
`Manatee.png` and `alligator.png` supplied by the project user: background
removed, cropped and scaled down for use as map icons.

`crocodile.png`, `dolphin.png`, `shark.png`, `turtle.png` and `whale.png` in
`../wildlife/` are Twemoji graphics (https://github.com/jdecked/twemoji),
Copyright Twitter, Inc and other contributors, licensed under CC-BY 4.0
(https://creativecommons.org/licenses/by/4.0/). Cropped for use as map icons.
